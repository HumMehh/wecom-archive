# 隐私与安全边界

## 采集

- 仅处理用户有权归档的数据，采集范围和用途由管理员在采集端管理中确认。
- 源数据库只读；DB/WAL/SHM 先复制到 exe 同级 `collectorData/work/<run-id>/`，再校验和解析，完成或失败后清理。
- 工作台本机采集不离开本机服务。已生成采集端按签名绑定配置同步心跳，用户手动上传或管理员显式启用计划后上传；默认计划关闭，程序不含遥测、更新检查或第三方资源。
- 企业微信注册表设置只读；自定义目录须为本机磁盘子目录，拒绝整盘、网络和父目录跳转，并在解析目录别名后再次校验。手动重试不回退到其他目录；仅成功采集后以当前用户 DPAPI 保护并记住目录。
- 数据脱敏启用时，在上传前不可逆替换账号、密码、令牌、联系方式和疑似凭据片段；文件名和图片名保留。

## 归档服务

- 未配置私有局域网采集端 URL 时默认只监听 `127.0.0.1:9812`；当服务端保存的 URL 明确使用私有局域网 IP 和端口时，启动时自动监听该地址。公网访问仍应通过 HTTPS 反向代理暴露已认证 API；访问令牌和私钥由 Windows DPAPI 保护。
- 只接受通过身份、签名、密文完整性、组织、密钥版本和归档契约校验的上传包。
- 媒体逐文件校验并按内容哈希原子存储；文件打开接口只接受归档哈希和安全扩展名，并限制在工作台数据目录。重复批次幂等处理，冲突批次拒绝写入。
- 错误响应使用稳定错误码，不返回数据库内容、密钥、内部路径或调用栈。
- HTML 导出全量转义并禁止脚本和远程资源；CSV 防公式注入；所有导出使用 `.partial` 原子完成且不覆盖已有文件。

## 外部大模型总结（可选）

这是全产品唯一会把归档内容送出本机的功能，因此默认关闭，并且不随程序附带任何厂商地址。

- 未在「沟通记录」弹窗中配置并开启前，工作台不发起任何外部请求；关闭时沟通记录仍然生成，总结列留空。
- 开启后，**被选中时间范围内的聊天正文**会以 `POST` 发送到管理员自己填写的接口地址，请求体包含系统提示词（管理员自己写的总结提示词，必填、无内置模板）与该会话的 Markdown 全文。每段会话一次独立请求，请求之间不共享任何历史，也不包含其他人的任何内容。
- 勾选「总结时附带图片」（独立开关，默认开启）时，**该会话自己的图片和语音**会随请求发送：图片以 base64 数据 URL 附上，语音在本地解码为 16 kHz 单声道 wav 后作为音频附上（原始 SILK 文件仍留在媒体目录，解码用的临时文件在请求构造完成前删除）。单次最多 8 张图、约 8MB base64；语音不限条数但同样计入体积上限，超出的留在本地媒体目录，并以文字告知模型哪些文件未随请求发送。
- 接口地址、模型名、总结提示词（必填）和 API 密钥由管理员配置。提示词是普通文本，随 `serverData/summary-settings.json` 明文保存（它只是模板，不是凭据）；密钥用当前用户 Windows DPAPI 保护后保存在同一文件，接口只回传「是否已配置密钥」，永不回传明文。
- 「测试连接」按钮会向所填接口发送一条固定短句（不含任何归档内容），并把 HTTP 状态码与响应原文回显在界面上，用于排查地址、密钥或协议不匹配；curl 的诊断信息（DNS、TLS、连接被拒等）一并回显。
- 总结失败不再静默：导出响应会带回首个失败原因，界面以红色提示显示，不再出现「导出成功但总结列全空」而无从排查的情况。
- 接口地址必须以 `http://` 或 `https://` 开头，否则请求被拒绝；请求体经标准输入传给 `curl.exe`，不出现在进程命令行中。
- 切换开关或接口地址属于产品级显式配置，应视为已获得相应员工授权。启用前请确认目标地址符合本企业的数据外发规定；公网地址应使用 HTTPS。
- 单个会话总结失败不会使整次导出失败，该会话的总结列保持空白。

## 日志和测试

日志只记录版本、阶段、计数、哈希前缀和错误码。真实聊天、账号、密码、令牌、加密密钥、私人路径和截图不得写入日志、测试产物或仓库。

## 尚未实现的组织级能力

当前访问控制适用于受控单节点部署。OIDC、RBAC、自动保留、legal hold、删除执行器和不可变审计存储尚未实现；在这些能力完成前，不应将当前版本视为完整合规归档平台。
