# 产品能力

| 能力 | 工作台与服务端生成采集端 |
| --- | --- |
| 本机源数据发现、解密与只读快照 | 支持直接采集本机和已生成采集端所在电脑 |
| 自定义存储目录 | 自动读取企业微信注册表设置；工作台采集或快速导出发现失败时可手动填写，成功后 DPAPI 记忆；后台任务复用 |
| 会话浏览、成员、引用和群信息 | 工作台支持；生成采集端不提供 |
| 搜索与筛选 | 工作台支持 SQLite/FTS5 全局搜索；生成采集端不提供 |
| 媒体 | 流式采集；图片预览，文件由默认应用打开；生成采集端按绑定配置上传 |
| 语音消息 | 与图片/文件共用媒体通道，原始音频随媒体采集落盘并可导出；未转写为文字，但总结时可解码为 wav 音频一并发送给多模态模型 |
| 数据脱敏 | 导出时可选；生成采集端上传前按目标配置执行 |
| 导出 | JSON、CSV、HTML、Markdown 单文件；支持脱敏、简化和美化；完整 JSON 可导入；生成采集端默认直接上传 |
| 沟通记录 | 按「姓名 × 月份」导出 Excel，一人一月一行，列为姓名、总结记录、时间、消息数、聊天记录、要点摘录（总结记录紧跟姓名，媒体不再单独占一列）；同月多会话自动合并且各会话保留独立原文与媒体；姓名取自企业微信解析出的备注（`real_remarks`），备注优先于昵称，群聊归入群名而不是首个发言人；可选仅个人会话、仅外部客户（按企业微信 `external_user_ids` 名单，区分同昵称的同事）；聊天记录不依赖大模型，超单元格上限自动截断。媒体就在「聊天记录」列里：单元格顶部是媒体提示，缩略图紧接其下（点击缩略图打开原图；放不下的留在媒体目录并在单元格注明），正文从图片下方开始，语音/附件在同一单元格内注明，单元格本身链接到该行的媒体目录（整个工作簿只有「一人一月一行」，媒体不另起一行） |
| 大模型总结 | 默认关闭；可配置接口地址（只填到 /v1 或 /api/paas/v4 这类版本路径即可，程序自动补全 chat/completions）、模型、密钥（DPAPI）与总结提示词（**必填，无内置提示词**）；提供「测试连接」返回 HTTP 状态与响应原文，未开启开关时也可先测试；**限流（429）、超时与 5xx 自动重试**（默认 3 次、等待时间递增），密钥/模型名错误不重试；**每次调用之间默认间隔 300 毫秒**避免长列表触发限流；每个失败的行都会写入诊断日志并在结果里逐个列出姓名与原因；单次请求超预算时自动分段总结再合并（map-reduce），个别分段失败时保留已成功的部分并在单元格注明。**每段会话独立调用一次模型**：系统提示词就是管理员自己写的那段，紧跟其后的是这一个客户的完整聊天记录（含其图片与语音），请求之间不共享任何历史，不同人的记录互不可见。图片与语音可随正文一并送出（「总结时附带图片」独立开关，默认开启）：企业微信 SILK 语音在本地解码为 16 kHz 单声道 wav 后作为音频附上，原始文件不变；单次最多 8 张图、约 8MB base64，语音只受体积约束不限条数，超出的留在本地并告知模型 |
| 数据汇集 | 增量、幂等合并并保留消息修订 |
| 传输保护 | 验证身份、签名和密文完整性；生成采集端使用控制信封签名 + RSA-OAEP-SHA256 + AES-256-GCM |
| 运行方式 | `WeComArchive.exe` 工作台模式；服务端生成已绑定采集端文件 |
| 后台持续采集 | 固定间隔或每日定时；采集端启用计划后立即采集上传一次，窗口、托盘和管理页展示最近成功 |
| 审计与保留 | 保存导入和修订审计；生成采集端不保存归档；自动保留策略尚未实现 |
| 组织身份与权限 | 当前使用访问令牌；生成采集端使用服务端预置设备令牌；OIDC/RBAC 尚未实现 |

会话导入支持生成采集端的加密 `.wca` 文件和工作台生成的契约 JSON；普通阅读导出文件不作为导入格式。
